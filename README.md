# NetworkTools

A collection of network security tools built in Python.

## Port Scanner

Fast multi-threaded port scanner built with Python sockets.

### Features
- 100 threads by default
- Scans up to 65535 ports
- Saves results as JSON
- Auto-creates results folder

### Usage
```bash
python3 NetworkTools/main.py
```

### Requirements
- Python 3.x
- No external libraries needed
